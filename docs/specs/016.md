## Proposal
1. **Repo visible in Docker.** In `docker-compose.yml` service `backend`: volume `.:/repo` replaces `./backend:/app`, and `working_dir: /repo/backend`. Then `Path(__file__).parents[2]` is `/repo` exactly as on a checkout, so no test changes its ROOT logic. The dev `runserver` command works unchanged from that workdir. The image's `COPY . .` into `/app` stays for non-compose builds. `frontend` service is untouched (its tests read only `frontend/`).
2. **Frontend always terminates.** No change to `package.json`; a backend-side test (below) pins `"test": "vitest run"` so a switch to watch mode is caught.
3. **Fast hasher only under pytest.** New `backend/sharelo/settings_test.py`: `from .settings import *` then `PASSWORD_HASHERS = ["django.contrib.auth.hashers.MD5PasswordHasher"]`. `backend/pyproject.toml` points pytest at it. `sharelo/settings.py` and everything prod/e2e/manage.py/wsgi use stays unchanged. Subprocess tests in `test_prod_settings.py` set `DJANGO_SETTINGS_MODULE=sharelo.settings` explicitly, so they exercise the real prod module.
4. Docs: README test section and `CLAUDE.md` §5 command table note that Docker mounts the whole repo at `/repo`.
