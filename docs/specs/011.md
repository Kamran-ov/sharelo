## Proposal
**Frontend stack** (fixed for 012–015): React Router v6, TanStack Query v5, Tailwind CSS v4 (`@tailwindcss/vite`, no config file), `openapi-typescript` generating `src/api/types.ts` from `schema.json` (npm script `types`; the generated file is committed and `make lint` runs `tsc` over it). No component library. Layout: `src/api.ts` (fetch wrapper), `src/auth.tsx` (`useMe`), `src/pages/{Login,Groups,Join,GroupShell,Settings}.tsx`, `src/components/{Sheet,GoogleButton,Placeholder}.tsx`. A page holds no business logic; it calls endpoints and renders. Strings in English.

**`api.ts`**: `api<T>(method, path, body?)` — `credentials: "same-origin"`, JSON in/out, for non-GET reads the `csrftoken` cookie and sends `X-CSRFToken`; if the cookie is missing it first does `GET /api/me` (which sets it) and retries reading once. A non-2xx response becomes `ApiError{status, code, detail}`; a non-JSON error body becomes `code: "network"`. A 401 never redirects from inside `api.ts`; the route guard decides.

**Routing and guard**: `/login`, `/groups`, `/join/:token`, `/g/:id/{expenses,balances,recurring,settings}` (default `expenses`). `RequireAccess` wraps `/groups` and `/g/*`: loads `/api/me`; `authenticated` or non-empty `guest_memberships` passes, otherwise `<Navigate to="/login">`. `/login` and `/join/*` are public; an authenticated user visiting `/login` goes to `/groups`. A guest with memberships opening `/groups` sees only their groups (the API already returns exactly the union; the page does not filter). Group-scoped 404 (non-member) renders "Group not found" with a link back, no redirect loop.

**Pages**
- Login: email + password, "Create account" toggle (adds display name, calls register), submit errors inline from `detail` (no redirect). "Sign in with Google" button rendered only when `me.google_enabled`; loads the GIS script on demand, calls `auth/google` with the ID token.
- Groups: list (name, currency, "main" badge, "linked to Home" for active-linked non-main groups); "New group" opens a bottom sheet: name, currency select (EUR first, then a fixed list of common ISO codes), "make this my main group" checkbox, default checked iff the profile has no main group and disabled otherwise (the API refuses a second main with `main_group_exists`; the UI does not offer it).
- Join: public preview (group name, currency, member names). Signed-in: one "Join" button. Guest: name field + "Join". `name_taken` shown inline. On success navigate to `/g/:id/expenses`.
- Group shell: header with group name, `<Outlet/>`, bottom nav of four 44 px+ tabs. Expenses/Balances/Recurring render a placeholder "coming in ticket 012/013/014". Settings: share link (`${origin}/join/${share_token}`) with a Copy button (`navigator.clipboard`, with a visible "Copied" state), the members list (so a guest sees her own name), and, for signed-in non-main members, the "Linked to Home" toggle posting `groups/{id}/link`.
- Layout: a single centred column `max-w-[480px]`, `min-h-dvh`, `overflow-x-hidden` on the root only as a seatbelt (the e2e asserts the real `scrollWidth`, so the seatbelt cannot hide an overflow from the test: the assertion reads `documentElement.scrollWidth`, which counts content overflowing `body` when `html` is not clipped; clipping is set on the column, not on `html`).

**Backend support for e2e (the only backend change)**
- `settings.py`: `E2E = os.environ.get("E2E") == "1"`. When set: `SESSION_COOKIE_SECURE = CSRF_COOKIE_SECURE = False` (plain http on localhost) and the auth throttle rate is lifted. Guard: with `E2E=1`, an `ALLOWED_HOSTS` entry other than `localhost`/`127.0.0.1` raises `ImproperlyConfigured`, so the flag cannot be left on in a deployed environment by accident.
- `ledger/management/commands/e2e_reset.py`: `CommandError` unless `E2E=1`. In one transaction truncates app data and seeds: profile `a@example.com` / `password1234` ("Alice") with Home (EUR, main) and partner profile B (`b@example.com`) as a second member of Home, plus one trip group "Rome trip" owned by B with a fixed `share_token` (`e2e-rome-token`) and members B only (A is not in it, so the join flow has someone to join). Uses `groups.create_group`/`join_group_by_token`, not raw inserts, so the fixture obeys the invariants. Categories survive (seeded by migration): the truncate is of ledger/accounts rows only, never `Category`.
- Playwright `globalSetup` runs `E2E=1 python manage.py e2e_reset` (a command that finishes, not a server) before the suite; a per-test `beforeEach` re-runs it through the same helper so every test starts from the known fixture.

**Playwright**: `frontend/e2e/*.spec.ts`, `frontend/playwright.config.ts`: `webServer` array — Django (`E2E=1 python manage.py runserver 8001 --noreload`) and `vite preview --port 4173` on the built bundle; `reuseExistingServer: false`; Playwright owns start and stop. `vite.config.ts` gains `preview.proxy` for `/api` → `127.0.0.1:8001` with `changeOrigin: false` (Host `localhost:4173` equals the browser Origin, same CSRF reasoning as dev). Project device: viewport 390×844 touch, Chromium (pre-installed at `/opt/pw-browsers`; config uses `PLAYWRIGHT_BROWSERS_PATH` as is, never `playwright install`). One worker, since tests share one database. A helper `shot(page, testInfo)` saves `docs/screenshots/011/<test-name>.png`. `make e2e` = `cd frontend && npm run build && npx playwright test`. CI job `e2e`: Postgres service, Python + Node setup, `make install`, `make e2e`; the Playwright report/PNGs are uploaded as an artifact.
